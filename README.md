# Claude Code — Home Assistant Addon Repository

Add this repository to your Home Assistant addon store:

1. Go to **Settings > Add-ons > Add-on Store**
2. Click the three dots menu (top right) > **Repositories**
3. Add: `https://github.com/sugendran/ha-claude`
4. The "Claude Code Terminal" addon will appear in the store

See [claude-code-terminal/README.md](claude-code-terminal/README.md) for addon details.
